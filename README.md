# 📸 IA Photo Search & Downloader

<p align="center">
  <b>Um Web App inteligente criado inteiramente pelo celular via Termux.</b>
</p>

O **IA Photo Search** é uma ferramenta de busca de imagens de alta resolução que utiliza a Inteligência Artificial do **Google Gemini** para interpretar pedidos em português e transformá-los em buscas profissionais no **Pexels**.

## 📱 Desenvolvimento Mobile-First
O grande diferencial deste projeto é que ele foi **100% desenvolvido em um ambiente Android**, utilizando o **Termux**. Isso demonstra o poder da computação móvel e como barreiras de hardware podem ser superadas com criatividade e as ferramentas certas.

## ✨ Funcionalidades
- **Busca via IA:** Otimização de prompts para resultados mais precisos.
- **PWA (Progressive Web App):** Instalável no celular, com ícone próprio e carregamento rápido.
- **Hospedagem Híbrida:** Frontend no **Firebase Hosting** e Backend no **Render.com**.
- **Persistência:** Histórico de buscas e galeria salvos via **Firebase Cloud Firestore**.

## 🛠️ Tecnologias
- **Frontend:** HTML5, CSS3 (Dark Mode), JavaScript.
- **Backend:** Python (Flask), Google Generative AI (Gemini).
- **Banco de Dados:** Firebase Realtime Database & Firestore.
- **Infraestrutura:** Git, GitHub, Render, Firebase.
